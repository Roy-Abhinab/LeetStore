### ➕ How to Add a New Problem

1. Find (or create) the `<details>` block for the right topic. If the topic doesn't exist yet, copy this skeleton to the bottom (above this section) and add it to the Table of Contents:

   ```markdown
   <details>
   <summary><h3>New Topic Name</h3></summary>

   | # | Problem | Difficulty |
   |---|---------|:---:|
   | 1 | [Problem Title](https://leetcode.com/problems/problem-slug/) | 🟢 Easy |

   </details>
   ```

2. To add a problem to an existing topic, just append a row (bump the `#` number):

   ```markdown
   | 5 | [Problem Title](https://leetcode.com/problems/problem-slug/) | 🟡 Medium |
   ```

3. Use the right emoji for difficulty: 🟢 Easy · 🟡 Medium · 🔴 Hard
4. Update the badge counts at the top when you feel like it (optional — purely cosmetic).
